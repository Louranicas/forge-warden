# Release checklist: forge-warden 0.2.0

This is the checklist for the 0.2.0 release as it stands at commit `6682ed53` (the frozen tree).
Each line that is done names the commit that did it. The lines at the end can only be done by
the repository's owner and are not ticked by anyone else. ADR 0011 (amendment A1) requires this
checklist to record which verdict schema 0.2.0 ships; that record is the first section.

0.2.0 is a breaking release (pre-1.0 semver): see [Upgrading from 0.1.0](UPGRADING.md).

## Decisions recorded before the tag

- [x] **Verdict schema (ADR 0011, A1).** The admitted Git runtime and verdict v2 merged before
  the 0.2.0 tag (`4451bfd`). So 0.2.0 ships `forge-warden.verdict.v2` directly. 0.1.0 shipped v0;
  v1 existed only between releases and no tagged release carries it. The changelog says so under
  `[0.2.0]` (`5c067c0`).
- [x] **Policy schema.** It stays `forge-warden.policy.v0`. The `[producer]` table is optional and
  additive; a policy without it works in advisory mode only. Two policies 0.1.0 accepted are now
  refused (no rules; a file over 1 MiB): [Upgrading](UPGRADING.md), section 6. Changelog `5c067c0`.

## Preconditions, all on the frozen tree

- [x] The front-door documents describe the modes, every child process and the determinism
  contract (`87a0f4b`), and tests keep the documents' commands and names equal to the code
  (`aa6d0ce`, `6947afe`).
- [x] The plant harness is part of the gate and its files are protected paths (`e1d74bc`, `2ae62fe`).
- [x] Named-file doors refuse FIFOs and devices; child processes are bounded and killed (`9ec6a84`).
- [x] Provenance is a type: a ranking is judged only through the authority and advisory entry
  points (`9cf88e9`, `5478daa`). This changed the public library API and is inside 0.2.0.
- [x] The producer is pinned by digest in `warden.toml`, and the dogfood driver fetches the pinned
  deep-diff-forge v0.8.2 release archive and checks it (`22d8199`).

## Gate

- [x] The integrator gate passed on `8555bf6`, whose tree the frozen commit carries: format, lints,
  tests, the supply-chain check, the MSRV build (Rust 1.88), the plant catalogue (110 of 110 plants

- [ ] The same gate on the final commit, which is the frozen tree plus the evidence package.
- [ ] A mutation baseline of the whole workspace on the frozen tree, recorded in `EVIDENCE.md`.

## Measured once, with a stated limit

- [x] Authority mode end to end on `6682ed53`: a docs-only change passed (exit 0), a protected
  path held (exit 8), a producer pin with one digit changed was refused (exit 4), and a Git that is
  not enrolled was refused (exit 3). Limit: the Git allowlist used was installed inside a rootless
  development container by an agent, not on a host by the owner. The run shows that the admission
  path, the pin and the refusals work; it does not show an owner boundary.
