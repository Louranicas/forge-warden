# Verdict schema history

`verdict.v1.schema.json` is superseded by v2, not produced. It is retained byte-for-byte as a historical document. `verdict.v2.schema.json` (0.2.x) is superseded by v3, not produced, and retained byte-for-byte: v3 changes only `seals.claims` (a boolean `verified`, and `merge_base` when bound mode made the diff, ADR 0012). Current output uses `verdict.v3.schema.json`; authority requires approved Git identity. Unpinned Git is advisory only.
